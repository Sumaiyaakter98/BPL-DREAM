# Dream 11 Cricket Team Builder

A responsive React web application where users can browse available cricket players, manage their coin budget, select players for their squad, and review or remove selected players.

🔗 **Live Demo:** [https://dream11xi.netlify.app/](https://dream11xi.netlify.app/)

## Features

- **Dynamic Player Listing:** Loads player data from `public/data.json` and renders player cards in a responsive grid.
- **Coin & Budget Management:** Deducts player price from available coins upon selection and notifies the user if coins are insufficient.
- **Available & Selected Tabs:** Switch smoothly between available players and the selected squad (`Selected (count)`).
- **Remove Selected Players:** Delete players from the selected list anytime.
- **Toast Notifications:** Instant feedback using `react-toastify`.

## Tech Stack

- **Frontend:** React, Vite
- **Styling & UI:** Tailwind CSS, DaisyUI
- **Icons & Notifications:** React Icons, React Toastify
